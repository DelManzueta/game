# CheatMod integration

Studio Empire's **Cheat & Debug** menu reimplements the player-facing fantasy of
[kristof1104/CheatMod](https://github.com/kristof1104/CheatMod) (Game Dev Tycoon)
as original Studio Empire systems — not a port of GDT save edits.

Features mapped: money tiers (1M–1B), set cash/fans, fan tiers, hype, RP,
Dream Team / B-Team, pro founder, final-level jump, all topics, perfect/no-bugs/
fast-research/no-vacation modes, design/tech +10/+100, time jump, cheat audit log.

License of CheatMod should be respected as inspiration only; no source was copied.
