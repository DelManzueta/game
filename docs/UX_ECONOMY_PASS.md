# UX + lifecycle + economy pass (grk)

## Lifecycle
- Production SWU bases +50% → longer stages (~6–7 weeks each).
- Size catalog weeks: small 10 / medium 20 / large 36 / AAA 64.
- Title sales shelf extended (launch→long-tail over months, not ~14 weeks).
- Dormant streak 6 → 10 weeks.

## Economy
- Higher base dev costs; lower salesMult.
- Default market capacity rate 0.0025 → 0.0016.
- Era sales dampener soft-caps runaway early-90s fortunes while later decades remain winnable.

## Events + save
- Events are decision popups (`pendingEvent`) with labeled choices.
- Saving mid-event preserves `pendingEvent` and restores `modal: "event"` on load.
- Time does not advance while a decision is open; cooldowns reserved on present.

## UI
- Every chrome control has its own visible text label (speed, inbox, orbs, menu).
- Stronger muted/subtle contrast; warm shared tokens; `data-era` restyle path.
- Removed unused `desk-ui.png` / `founder-ui.png` frames.
