# Studio Empire — Product Constitution

**Status:** North star (tech-lead locked)  
**Source:** Comprehensive Build Report, Aug 2026  
**Rule:** Reimplement the *fantasy*, not a literal GDT port. **All systems are core game — never expansion packs.** See [FOUNDATIONAL_CORE.md](./FOUNDATIONAL_CORE.md).

## Vision (one paragraph)

A modern, deterministic, browser-based game-development tycoon: one founder in a garage → multi-team software, publishing, and hardware empire. Combines GDT’s approachable project loop, Expansion Pack late-game breadth, OpenTTD/Simutrans economic legibility, Studio Empire’s deterministic production/quality/market systems, Warm Industrial Editorial UI, and a full Cheat & Debug suite.

## Feel

- Personal early · strategic later · understandable · not auto-solved  
- Deterministic (save cannot re-roll frozen outcomes)  
- Replayable seeds · economically causal · visually coherent · long-lived products · continuous late-game systems (all core)  

## Core loop (never replace, only expand)

Market → concept → engine/team → Stage 1 → Stage 2 → Stage 3 → polish → price/marketing/distribution → release → reviews → weekly sales → report → learn → research/hire/recover → next game.

## Non-negotiables

0. **One complete core game** — platforms, research, engines, training, hardware, R&D, AAA, online/MMO/live services, subscriptions, publishing, and future tech are native. Never present systems as mods, DLC, add-ons, or expansion packs ([FOUNDATIONAL_CORE.md](./FOUNDATIONAL_CORE.md)).  
1. **Three strict stages** with shared effort (no maximize-everything).  
2. **Quality ≠ marketing** — awareness never rewrites product quality.  
3. **Determinism** — freeze reviews, completed sales weeks, ledger, knowledge.  
4. **Multi-dimensional difficulty** independent of **information mode** (Classic / Assisted / Analyst).  
5. **One design system** (Warm Industrial Editorial) across eras.  
6. **Complete Cheat & Debug menu** for every progression phase.  
7. **Original content** — GDT / Expansion Pack material is research reference only, never shipped pack structure.
