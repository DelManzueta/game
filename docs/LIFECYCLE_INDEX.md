## Shared principles (all parts)

1. **Overlapping lifecycles** — not a single linear unlock ladder.  
2. **Hear → prepare → unlock → invest → use → master → industry moves on → retire/preserve → keep history.**  
3. **Sunset limits the future; never erases the past.**  
4. **Industry clock ≠ company clock ≠ capability clock.**  
5. **Capacity containers grant capacity, not free staff/research/engines/quality.**  
6. **Events apply on sim date; messages are notifications, not causes.**  
7. **AAA = scale; MMO = architecture; neither is a genre.**

- Campus = **12 Tech Park years** + affordability; no L7 GPU gate.
